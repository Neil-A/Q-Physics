# How to work here

Read `README.md` first. It tells you where each document is.

## How to write

**Write in ASD-STE100 Simplified Technical English.** This applies to replies, documents,
commit messages, pull request text and code comments. Use simple words, one word for one
thing, and short sentences in the active voice. The full rules are in
`.claude/output-styles/ste100.md`. Code, quotations and existing text stay as they are.
